# nodzsound - Reaper Scripts
This repository contains a number of reaper scripts that help me to work more effective in Reaper. Some of these scripts were suggestions by members of the audio community https://airwiggles.com. May those scripts be helpful to you. 

## 01 - Installation
### Step 1: Install reapack
Install the reapack extension for Reaper from [here](https://reapack.com/).

### Step 2: Add the repository to reapack 
* Open the menu item 'Extensions -> ReaPack ->ManageRepositories
* Navigate to 'Import/export -> Import repositories
* Add this Url: https://github.com/nodzsound/reaper-scripts/raw/master/index.xml
* Now the repository "nodzsound - Reaper Scripts" should appear in your repository list

### Step 3: Download Scripts
* Rightclick with your mouse on the repository
* Set the option "Install new packages" to "When synchronizing". That way you will automatically get all new scripts and updates whenever you synchronize your ReaPack repositories
* Close the repository manager
* Synchronize your ReaPack repositories via 'Extensions -> ReaPack -> Synchronize Packages

### Step 4: Verify
* Open your action list and search for 'nodzsound' 
* All scripts from the repository should appear in your action list

## 02 - Included Script Features
- **Copy Item Properties:** A collection of scripts to copy item properties from one item to another. The supported item properties are Item Length, Item Fade-In, Item Fade-Out, Take Pitch, and Take Playrate. Visit [this page](https://github.com/nodzsound/reaper-scripts/wiki/02-%E2%80%90-Package:-Copy-Item-Properties) for more information.
- **Lock Tracks:** You can use these scripts to lock track controls, items, and the take selection of all selected tracks. This is more convenient than to switch the lock state of each track, item, and take manually and brings reapers lock features closer to other DAWs. Visit [this page](https://github.com/nodzsound/reaper-scripts/wiki/03-%E2%80%90-Package:-Lock-Tracks) for more information.
- **Gluerip:** The GlueRip package enables you to rip previously glued items apart, by replacing the standard glue action and saving information about glued items in the project file. **Important:** This package is in its Alpha state. While basic functionalities for glue and rip should work, there is no guarantee that GlueRip won't break your reaper projects. I advise against using GlueRip in critical production environments at this time! Visit [this page](https://github.com/nodzsound/reaper-scripts/wiki/04-%E2%80%90-Package:-GlueRip) for more information.
